# Python Programming Practice

A collection of beginner-friendly Python programs created while learning Python fundamentals. This repository covers core programming concepts including basic syntax, functions, Object-Oriented Programming (OOP), file handling, and exception handling.

---

## 📂 Repository Structure

```
.
├── basic.py
├── function.py
├── OOP.py
├── file_handling.py
├── file_Exception_handilng.py
└── file_handling_practice.txt
```

---

## 📚 Topics Covered

### 1. Basic Python (`basic.py`)
- Variables and Data Types
- User Input
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`for`, `while`)
- Countdown Timer
- Pattern Printing
- Lists, Tuples, Sets, Dictionaries
- Quiz Game
- Rock-Paper-Scissors Game
- Functions

---

### 2. Functions (`function.py`)
- Function Creation
- Calculator using Functions
- Passing Parameters
- Returning Values
- Match-Case Statement
- Day of the Week Program

---

### 3. Object-Oriented Programming (`OOP.py`)
Examples demonstrating the four pillars of OOP:

- ✅ Classes & Objects
- ✅ Encapsulation
- ✅ Inheritance
- ✅ Polymorphism
- ✅ Abstraction (Abstract Classes)

The examples are based on a **Vehicle** class hierarchy.

---

### 4. File Handling (`file_handling.py`)
Examples include:

- Reading text files
- Reading line by line
- Reading all lines
- Appending data
- Closing files properly

---

### 5. File Exception Handling (`file_Exception_handilng.py`)
Demonstrates handling common file-related errors using:

- `try`
- `except`
- `FileNotFoundError`
- Generic exception handling
- Safe file operations using `with open()`

---

### 6. Practice Text File (`file_handling_practice.txt`)
A sample text file used for practicing:

- Reading
- Writing
- Appending
- Exception Handling

---

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/python-programming-practice.git
```

2. Navigate to the project folder

```bash
cd python-programming-practice
```

3. Run any file

```bash
python basic.py
```

or

```bash
python function.py
```
